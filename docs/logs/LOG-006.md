# LOG-006 — Controlled SPF feature and estimator ablations

Date: 2026-10-01. Protocol recorded before running these variants. Original result and implementation methodology remain in LOG-004/005; original artifact `data/research/spf/macro_spf_pilot.json` must not be overwritten.

## Question and evidence boundary

The original learned models deteriorated in the late evaluation block. `respondents` is a survey-administration count and possible time/regime proxy. **It has not been established as the cause.** Survey disagreement, context freezing, class scarcity, model stochastic/preprocessing choices and regime change are alternatives. The earlier aggregate comparison describes one feature/configuration bundle, not an architecture-level verdict on TabPFN versus professional consensus.

These are post-result exploratory diagnostics on already seen outcomes, not a new holdout or a basis for a significance claim. Preserve all variants, including unfavorable ones; do not replace the original score with the best variant.

Respondent counts are lower recently but not a simple monotone time trend:

| Survey years | Quarters | Count min / median / max |
|---|---:|---:|

Across all 131 eligible quarters, Pearson correlation between respondent count and
quarter index is **−0.11365**. A global linear correlation cannot rule out nonlinear
regime information; it does contradict treating a strong monotone trend as an
already-established fact.

**Diagnosis:** respondent count is not necessary for this failure pattern, and the
deletion experiment does not support it as the dominant removable cause. This
does not prove the original models ignored count: correlated predictors can
substitute, and changing a feature set changes the fitted ensemble. Broader
disagreement features affect TabPFN's Brier errors, but substantial errors remain
with means alone. Underlying data scarcity, context staleness, regime shift and
specific learned mappings remain unresolved explanations; no causal feature
attribution or architecture-level conclusion is warranted.
