## Initial judgment

The most interesting hypothesis is **small-sample conditional probability combination**, not generic next-price forecasting. A pretrained tabular inference engine might add value when nonlinear interactions exist but independent events are scarce. That remains an empirical hypothesis. Data availability at the decision time is likely the binding constraint, rather than model architecture.

Maintain separate tracks:

1. **Economic science target:** CPI release probabilities, then payrolls/FOMC only as separately specified tasks. First verify initial-release labels, exact release times, archived consensus/nowcasts, and market quotes.
2. **Fast model/data engineering pilot:** realized volatility or risk on liquid instruments, using genuinely historical market data. This checks chronological evaluation and model execution; it does not substitute for the economic experiment.
3. **Forecast combination:** compare economic-only versus forecast-enriched feature sets on identical event samples. Without archived forecasts, collect prospectively rather than reconstructing LLM predictions after outcomes are known.
4. **Secondary ideas:** post-earnings returns, drawdown, recurring weather markets; prioritize only after auditing point-in-time data and independent event counts.
5. **Model comparison:** TabPFN-3.5 and LimiX-2 versus historical frequency, logistic/ridge regression, boosted trees, and applicable market/consensus/persistence benchmarks. Never infer financial leadership from TabArena rank.

## Evaluation contract

- One independent event is one release, not each threshold/snapshot/ticker sharing that event.
- `feature_available_at <= decision_at`; historical labels enter training only after resolution. Release/reference dates and availability timestamps are distinct.
- Chronological walk-forward; purge overlapping label windows; fit transforms, tuning and calibration using past data only.
- CPI target: initially published headline CPI-U seasonally adjusted monthly percentage change, published rounding, strict `> 0.3%`; previous business-day fixed cutoff must be frozen in New York time. A rounded 0.3% is false. Do not derive the target from today's revised index levels.
- Primary probability metrics: Brier, log loss, reliability; compare paired predictions on identical dates with event/block uncertainty. For volatility: loss against realized variance, persistence and conventional volatility models, not price-level R-squared.
- Use out-of-sample base forecasts for combination; no in-sample stacked predictions or retrospective LLM forecasts.
- Separate predictive improvement from executable economics: spreads, fees, slippage, latency and liquidity are a later gate.
- Preserve a final holdout/prospective stream after exploratory choices. A small pilot win is not confirmation.
