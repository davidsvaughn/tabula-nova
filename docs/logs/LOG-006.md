Date: 2026-10-01. Protocol recorded before running these variants. Original result and implementation methodology remain in LOG-004/005; original artifact `data/research/spf/macro_spf_pilot.json` must not be overwritten.

## Question and evidence boundary

The original learned models deteriorated in the late evaluation block. `respondents` is a survey-administration count and possible time/regime proxy. **It has not been established as the cause.** Survey disagreement, context freezing, class scarcity, model stochastic/preprocessing choices and regime change are alternatives. The earlier aggregate comparison describes one feature/configuration bundle, not an architecture-level verdict on TabPFN versus professional consensus.

These are post-result exploratory diagnostics on already seen outcomes, not a new holdout or a basis for a significance claim. Preserve all variants, including unfavorable ones; do not replace the original score with the best variant.

Eight estimators test the ordinary ensemble size, not a different checkpoint or Thinking/Plus. Changing feature subsets can also change the ensemble's preprocessing/permutations, so a deletion ablation measures configuration sensitivity—not a unique causal attribution to that column.
