Date: 2026-10-01. This log records executed work, including failures. The initial plan is [LOG-001](LOG-001.md); the consolidated source inventory is [DATA-SOURCES](../DATA-SOURCES.md).

## 1. Model claims checked against primary sources

- [TabPFN-3.5 report v2](https://arxiv.org/html/2609.17895v2), published September 15 and revised September 22: 220M parameters; Fast 84M; one checkpoint for classification/regression; default 8 estimators versus Fast 4. Tuned/ensembled MLPs still lead some full grouped/temporal/large slices. Benchmark claims must include inference configuration.
- [TabPFN-TS](https://github.com/PriorLabs/tabpfn-time-series) v1.3.0 defaults to 3.5 in local/client mode. Past-only dynamic and static covariates are dropped. Multiple target columns become independent univariate tasks. A richer finance experiment should use an explicit decision-time table.
- [LimiX-2 repository](https://github.com/limix-ldm-ai/LimiX) documents 400M parameters and classification/regression/imputation; release September 16. Its displayed TabArena comparison includes TabPFN-3, not 3.5. No live leaderboard order was independently certified, and no LimiX time-series financial performance was demonstrated here.
- Both Hugging Face metadata endpoints returned HTTP 200 and `gated=false`. TabPFN repository revision: `06bf2ba35c80a92a3b9abb436b99cf49e7a0365e`; LimiX: `de07b679e74a41b50b9de18251a8fa245e537440`. **This does not establish runnable authorized access:** TabPFN's package enforces a separate license-authentication gate.

### License findings that change the plan

[TabPFN license](https://huggingface.co/Prior-Labs/tabpfn_3_5/raw/main/LICENSE) restricts weights and outputs to non-commercial/non-production use; internal preliminary evaluation is described as allowed, but commercial decisions and deployment need separate rights. It also contains an unusual professional-status/consumer exclusion. [LimiX license](https://huggingface.co/stable-ai/LimiX-2/raw/main/LICENSE) explicitly excludes research intended to support commercial objectives in a commercial entity and restricts outputs/competitive uses. Neither is blanket permission for trading research-to-production. User/license-owner review is necessary before applying outputs commercially; this is not legal advice.

No license checkbox was accepted, no gate bypassed, no cloud data upload or model inference API purchase made. LimiX weights/inference were not run; evaluate its license fit before installation for a trading-oriented project.

## 2. Runtime experiment and exact blocker

Commands executed from tabula-nova:

```sh

.venv/bin/python -c 'import torch, tabpfn; print("torch", torch.__version__, "cuda", torch.cuda.is_available()); print("tabpfn", tabpfn.__version__)'
```

The unconstrained install selected Torch `2.14.1+cu130`; CUDA initialization failed because the installed driver was too old for that build. No driver/system change was made. Corrected locally:

```sh
uv pip install --python .venv/bin/python 'torch==2.10.0' --index-url https://download.pytorch.org/whl/cu128
.venv/bin/python scripts/volatility_pilot.py
```

The corrected run passed the CUDA availability guard and reached `TabPFNRegressor.fit`, then failed with **`TabPFNLicenseError`**. Required steps from the exception:

1. User logs in to https://ux.priorlabs.ai.
2. User reviews/accepts the applicable license on the Licenses tab.
3. User obtains their API key from https://ux.priorlabs.ai/account.
4. Export `TABPFN_TOKEN` before local fit. A Hugging Face read token is not that token.

The target token is not present among tabula-nova `.env` names. No weight-download bypass or substitution with v2/Fast was attempted. **No TabPFN predictions or scores were produced.**

### Schwab — success

Used alpha-claw's existing `.venv/bin/python`, CWD alpha-claw, and:

```python
from alpha_claw.retrieval.providers import schwab_price_history
payload = schwab_price_history(
    "SPY", periodType="year", period=5,
    frequencyType="daily", frequency=1, needExtendedHoursData=False,

```

Returned **1,255 daily candles**, 2021-10-01–2026-10-01. Saved public market payload plus SHA256/request/date manifest under `data/research/schwab_spy_daily*`. The October 1 bar was incomplete at retrieval and is excluded from the pilot. No forced token refresh, websocket, order/account call or history-cache write was requested. Normal SDK access-token renewal is possible; it is not a seven-day OAuth reset.

### Finnhub economic calendar — unavailable on exercised credential

`GET https://finnhub.io/api/v1/calendar/economic?from=2026-09-01&to=2026-09-30` returned **403** using the configured credential. This agrees with the connected project's premium-entitlement warning. It does not prove every Finnhub endpoint is inaccessible. No subscription change attempted.

### BLS — usable reader access, direct HTTP blocked

Direct Python GET for https://www.bls.gov/news.release/archives/cpi_01112024.htm returned **403**. The read tool successfully retrieved the same archived release: December 2023 headline seasonally adjusted monthly CPI was **0.3%**, released January 11, 2024 at 08:30 ET. Therefore the strict `>0.3%` label is false. Original press-release values must not be replaced by revised CPI index calculations.

The [BLS archive](https://www.bls.gov/bls/news-release/cpi.htm) explicitly marks October 2025 CPI as not published. The [Cleveland Fed nowcast documentation](https://www.clevelandfed.org/indicators-and-data/inflation-nowcasting) explains its special handling. Missing official releases require exclusion or a separately specified resolution rule, never a fabricated official target.

### Kalshi — important positive result

Public requests used no private key:

- `GET /trade-api/v2/series?category=Economics`: **200**, 881 series.
- `GET /trade-api/v2/historical/cutoff`: **200**; market archive boundary `2026-08-02T00:00:00Z` at probe time. The boundary moves; never hardcode it.
- `GET /trade-api/v2/historical/markets?series_ticker=KXCPI&limit=1000`: **200**, 483 markets, **61 event tickers**, empty cursor (one complete response for that query). Close dates span 2021-07-12–2026-07-14. Newer events require the live tier; legacy `CPI` series may add/differ in coverage and is not yet audited.
- Exact title `Above 0.3%`: **53 contracts**, 19 yes / 34 no. These counts are coverage checks, not fitted priors or out-of-sample scores.
- `KXCPI-26JUN-T0.3` rules explicitly say greater than 0.3% single-decimal CPI in June 2026. Market result no; vendor `expiration_value=-0.4`. One seven-day historical hourly candle query returned **200 and 30 candles**. Follow-up reconciliation with the [original July 14, 2026 BLS release](https://www.bls.gov/news.release/archives/cpi_07142026.htm) confirmed headline SA monthly **-0.4%**, embargo 08:30 ET. One label is independently reconciled; the remaining history is not yet certified.
- An initial substring-selected sample was `Above -0.3%`, not the desired positive threshold. The subsequent exact-title/rules check corrected the probe. Both are retained and labelled in the artifact. This demonstrates why substring ticker/title matching is unsafe for target construction.

Saved full market metadata, rules, sample candles and cutoff in `data/research/kalshi_cpi_probe.json`. Dollar prices and contract volumes arrive as strings. Sparse candles and quote age need auditing before a fixed pre-release cutoff can be scored; 30 candles in seven days does not prove complete hourly coverage.

**Plan update:** CPI historical market data is obtainable. The initial concern is now a missing acquisition/join pipeline, not an unavailable historical API. The hard part is assembling comparable decision-time covariates, authoritative first-release labels and archived consensus/nowcasts.

## 5. Executed baseline pilot

After the explicit model gate failure, ran:

```sh
.venv/bin/python scripts/volatility_pilot.py --baselines-only
```

This is labelled `execution_mode=baselines_only` in the artifact. No silent fallback exists: without the flag the script still attempts the requested TabPFN model and raises if blocked.

Frozen pilot design was written before seeing scores:

- SPY only; six close-known features: RV5, RV22, one-/five-day log returns, log high/low range, relative volume.
- Target: annualized mean squared close-to-close log return over the next five trading sessions; learned models fit log variance.
- Three 100-session evaluation blocks, 500 historical training rows each. Training label end strictly precedes block start. Test every fifth session: 60 nonoverlapping forward windows.
- Fold first decisions: 2025-07-16, 2025-12-05, 2026-05-01. Last scored decision 2026-09-17, resolved 2026-09-24. The final unused days reflect five-session sampling, not missing labels.
- Fixed hyperparameters and seed 17; no tuning/search. Standardization fit only on each training block. Post-close features are not claimed executable at that same close.

| Method | QLIKE, lower better | Log-variance MSE, lower better |
|---|---:|---:|
| RV5 persistence | 1.067880 | 1.264028 |
| RV22 persistence | 0.537881 | 0.923392 |
| Ridge on log variance | **0.304908** | **0.593839** |
| Histogram gradient boosting on log variance | 0.385673 | 0.695842 |
| TabPFN-3.5 | **Not run: license gate** | **No score** |
| LimiX-2 | **Not run** | **No score** |

Ridge beat the other exercised methods in all three blocks on both metrics. This is useful evidence that a strong simple baseline matters; it is not a trading result, a statistically established advantage, or a TabPFN comparison. Only 60 outcomes, one ETF, unvalidated historical adjustment semantics, no untouched confirmation set. Log-trained/exponentiated forecasts need not be optimal conditional-mean variance forecasts under QLIKE.
