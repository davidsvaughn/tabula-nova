## Feasibility decision and frozen initial CPI protocol

**Data and source reconciliation are feasible; a strict historical forecast/market
comparison is not yet certified.** Do not turn nominal update schedules, candle-end
ages or retrospectively known release dates into observed availability. Matching
monthly survey consensus remains unavailable. This checkpoint completes the
acquisition/coverage stage, not the modeling or market-beating claim.

Freeze this initial, restricted-information release-distribution comparison before
seeing any CPI model scores; richer vintage covariates/forecast combinations are
separate later configurations, not silent additions:

1. **Target/cohort:** archived headline CPI-U SA MoM print in percentage points;
   one event per reference month, never one observation per market strike. Exclude
   absent targets; require calendar lags 1, 2, 3 and 12 whose labels were available
   before the retained 16:00 ET cutoff. No latest-vintage inputs or target filling.
   Current frozen eligible count is **303**.
2. **Chronology:** 2001-01–2009-12 warmup, **108 events**; 2010-01–2019-12
   development, **120**; 2020-01–2026-08 confirmation, **75**. In confirmation,
   missing 2025-10/11 targets and incomplete 2025-12–2026-02 lag contexts remain
   exclusions. Confirmation is untouched by CPI model-score selection. Report
   both periods; do not rename a favorable subset confirmation.
3. **Information and context:** four original-print lags plus deterministic
   sine/cosine month-of-year features. Each query uses only the latest 120 eligible
   past rows, minimum 48, with labels available by its cutoff. Refit/query one event
   at a time; no concatenated future queries or future-fitted preprocessing.
4. **Declared point-model configurations:** historical training-target mean;
   standardized ridge (`alpha=1`); histogram boosting (`max_iter=100`,
   `max_leaf_nodes=7`, `learning_rate=0.05`, `min_samples_leaf=10`,
   `l2_regularization=1`); local TabPFN-3.5 regression, eight estimators; official
   LimiX-2 regression, 32 pipelines without partial-ensemble fallback. Fixed seed
   17. Confirm each real regression API/output and memory bounds in a smoke before
   full inference; failure is recorded, not silently replaced by classification.
5. **Distribution rule, common to point models:** keep the last 60 signed,
   genuinely past walk-forward prediction errors from each model. Produce
   pre-evaluation warmup predictions for 2005-01–2009-12 (60 events); each uses
   at least the 48 preceding eligible training rows. The predictive sample is the
   current point prediction plus those past errors. Retain it unrounded; derive
   printed-label probabilities by decimal half-away-from-zero rounding to 0.1.
   This is an empirical residual distribution, not a claimed native LimiX
   posterior. Never estimate its width from development/confirmation future errors.
6. **Scores:** primary continuous CRPS in percentage points; MAE, declared
   10/50/90 quantile losses and 80% interval coverage; derived strict `>0.3%`
   Brier as secondary. Compute each threshold from the same release distribution.
   Do not add smoothing/log-density assumptions merely to report a finite log score.
   Report paired model-minus-baseline differences and a fixed 12-month moving-block
   bootstrap (2,000 replicates, seed17), without treating strikes as independent.
7. **Separate comparison gates:** Cleveland stays a dated point-forecast candidate,
   not monthly survey consensus or an immutable forecast distribution. Kalshi
   remains a separate rule-consistent, actual-cutoff, quote-age-eligible cohort.
   Neither silently narrows the main official-target cohort. No claim to beat
   consensus or market probabilities without those matching baselines.
8. **Run gate:** reconcile archived correction notices, prior-announced schedules
   and exceptional closure handling before calling this a strict PIT comparison.
   Preserve remaining source-clock assumptions in every result. The API smoke and
   implementation may proceed; full scored inference waits for this availability
   audit. Do not substitute an unannounced retrospective-capability benchmark.
