## Real initialization failure and narrow upstream patch

The first real constructor attempt correctly reported `arch_version=2.0` but failed:

```text
PermissionError: [Errno 13] Permission denied: '/mnt/public'
```

The official v2 predictor unconditionally initializes its cache at `/mnt/public/lijiansheng0830cache`, even with `use_data_cache=False`. No sudo, system-directory creation, or exception suppression was used. Patched the isolated source to read `LIMIX_CACHE_DIR`, defaulting to `~/.cache/limix`; the comparison sets it to its ignored local runtime directory. Exact change is versioned in `patches/limix-local-cache.patch`. It changes storage placement, not model architecture, weights, features, prediction rules or ensemble membership.

## Protocol declared before LimiX scores

- Reuse the LOG-004/005 frozen cohort, first-release target definition, 43/71/99 training events, four-quarter target-period embargo, and three 28-event test blocks: 84 evaluation quarters / ten contractions.
- Primary LimiX run uses **all ten original features**. No selection based on LimiX scores, no repeated feature search; comparisons include the already saved full-feature TabPFN two/eight-estimator results and unchanged conventional baselines/consensus.
- Use the official v2 no-retrieval classification config, **all 32 preprocessing/ensemble pipelines**, seed 17 and default classification temperature/mixed precision. This is the official LimiX configuration, not an equal-ensemble-size or equal-compute architecture experiment.
- Single GPU, four CPU math/preprocessing threads, no DDP, no persistent data cache, reuse one loaded frozen model. Record actual model/config/source hashes and peak Torch CUDA allocation/reservation.
- Disable the config's CUDA-resource partial-ensemble retry. Reject any recorded resource-driven pipeline/feature fallback instead of silently scoring a reduced ensemble.
- **One query quarter per `predict` call.** Source inspection found v2 classification concatenates train and query features and fits member preprocessing on that concatenation (`predictor.py`, original lines 2934–2976 and 2623). Passing all seven future years as one query batch would expose future quarters' feature distributions to earlier forecasts. A single contemporaneous query keeps that model-native transductive preprocessing inside the forecast information set; no query labels are passed.
- Preserve the original artifacts. Verify reconstructed events, input hashes, labels and training boundaries against the existing artifact, then append LimiX probabilities to a separate output. Never publish a partial run as the 84-event result.
- Report Brier/log loss and per-block behavior, actual runtime/resource use, and every failed attempt. All earlier sparse-positive, outcome-vintage, historical-correction and exploratory-cohort caveats remain. Neither model's causal-awareness claims establish macro intervention effects.

configuration. This does not identify a common causal mechanism or prove that
