## New macro source discovery and predeclared next probe

The Philadelphia Fed provides both [SPF probability forecasts](https://www.philadelphiafed.org/surveys-and-data/recess) and [first/second/third release macro values](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/first-second-third) without a FRED API key. Direct HTTP downloads of individual RECESS forecasts, mean forecasts, GDP release values, and SPF publication dates all returned 200.

Important semantic correction from the [SPF FAQ](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/spf-faqs): RECESS is **probability of negative quarterly real GDP growth**, not probability of an NBER recession. RECESS2 predicts the following quarter. The individual file has 9,280 forecaster rows across 232 survey quarters, through 2026Q3; these are 232 shared macro events, not 9,280 independent outcomes. Pre-1992 questions concern GNP, not GDP. Publication dates exist from 1990Q2; that first survey was retrospective. First GDP releases are missing for 2025Q3/Q4 in the downloaded release file; do not fill with latest-revised values.

Before looking at macro scores, declare a small feasibility experiment:

- Target: next-quarter real GDP growth strictly negative in the archived **first-release** column. Use survey quarters 1992Q1 onward and evaluate 2004Q1–2024Q4, avoiding GNP-era mixing and the known recent missing-release entries.
- Features: the five contemporaneous SPF mean contraction probabilities plus next-quarter cross-forecaster dispersion/median and response count. No hindsight-generated LLM features or current revised macro inputs.
- Baselines: direct SPF mean probability, training frequency, regularized logistic calibration, conservative boosted trees. Candidate: the same local standard TabPFN-3.5 classifier with two estimators.
- Three fixed seven-year evaluation blocks (2004–2010, 2011–2017, 2018–2024). Training is frozen at block start, with a conservative four-quarter target-period embargo. This is deliberately not an optimized online combiner.
- Use actual SPF publication dates. The embargo is an explicit timing assumption, not a substitute for audited exact GDP release timestamps; label the result a retrospective feasibility study until complete historical availability is certified.
- Metrics: Brier and log loss; report event count and negative-outcome count. No random row split, no tuning, no forecast submission, no NBER recession claim.

This directly exercises broad macro probability combination while the two requested reference investigations continue. The small number of contractions and historical archive corrections remain central limitations regardless of score.
